# 按图片判断整体缩放倍数

现有三路图片分析同时返回 `faces`、`scale_factor` 和 `scale_reason`。面数按轮廓复杂度选择3000–5000；倍数按素材的整体体量选择100–300。两项独立判断，面数不能证明物理尺寸。

示例：

```json
{"faces":4200,"scale_factor":240,"scale_reason":"多峰连体山群，基底宽厚，作为大型中远景素材"}
```

原面数解析节点在原位置替换为 `BAMidFarFaceCountFromAnalysis`，只读 `faces`，不受字段顺序和其他数字影响。原 `faces` 接线保留。分析文本同时接入 `BAMidFarModelAudit` 的 `analysis_1/2/3`；启用 `scaling_mode=analysis_range`，设置 `min_scale_factor=100`、`max_scale_factor=300`。

模型所有轴使用同一倍数，保留原长宽高比例、场景层级、天然连接和贴图。仍归位到底部中心，仍检查实际三角面、导出几何和三路来源。

有效建议在范围内直接使用；正数超范围限制到边界；缺失、无效、非有限或布尔建议回退到范围中点200。最终报告逐路记录原建议、实际倍数、范围、来源、理由和计划面数。回退或限制会成为验收警告；严格验收开启时，警告阻止整批模型发布。

完整画布删除原尺寸节点 #34 及其接线。范围模式拒绝同时连接旧 `scale_plan` 或 `scale_factor_1/2/3`，防止旧最长边归一化继续生效。`manual` 为兼容默认模式，旧画布不自动改变行为。

图片不能提供真实世界的绝对尺寸，倍数是素材用途与形态判断；导出报告中的宽高深仍为模型坐标单位。
