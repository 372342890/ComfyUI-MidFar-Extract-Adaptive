# 五路山体提取方案

目标：同一原图提取最多三个完整山体和两个远景山脉，五个图片模型分支同时就绪，只运行提取及查重。

1. 一个原图识别节点统一选择五个自然单元，一个独立 PE 节点逐项写提示词。山体与山脉身份统一查重；相连峰群不得拆份。缺少实际目标时记录缺口，不补虚构目标。
2. 本地校验实际识别和 PE 的对应关系，生成固定身份的执行工作流。当前云端复用已安装的三路节点，不依赖未经部署的新节点。
3. 五个图片生成节点并列连接同一原图，不互相依赖。查重组为 123、145、245、345，覆盖全部十对。最后一组依赖前三组的检查输出，单独执行它可触发完整五路提取和全部检查。
4. 校验包含同图、镜像、主体变体；保存各组真实记录。局部包含另外检查原图目标身份和实际图片，不把低证据的相似轮廓称为确定重复。
5. RED：验证五个身份、跨类型重复、缺位、十对覆盖和五图平行依赖。GREEN：实现、完整回归、导入实际图、真实运行。Review：逐图看峰形、连续性、远景层次及全部配对，保存图片和记录。

本方案不修改已发布的三路节点契约。当前任务没有新增 Git 提交或发布授权。
