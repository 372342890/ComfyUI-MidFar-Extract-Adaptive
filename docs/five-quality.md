# 一张原图 → 三张近景、两张远景

新版完整工作流是 `midfar-five-quality.byteartist.json`。用户只替换一个上传入口的原图，识别、PE、动态定位、五路生成、检查、条件重试和最终保存均已连接，不再手工把规划结果拼成执行图。

## 固定输出

- 第1～3路：当前图里的三个不同近景自然山体，距离层字段为 `midground`；可以是完整单峰、连体山群或独立岩台。
- 第4～5路：当前图里的两个不同远景连续山脉，字段为 `background`；保留远景空气透视。
- 最终五张图为2048×2048 PNG，默认白底，保留目标自身雪面；四侧至少15%留白，宽高各不超过画布70%，仅等比缩放。
- 同组双峰、共享岩肩和岩基必须完整提取；远景小山不能填近景路，两个远景不能共享同一主峰段。

原图确实缺少合格单元时，准入节点说明不足并停止正式五路输出。复制、拆同组、镜像、改色或臆造连接不能用来凑数。本链路不保证任意缺少可用目标的图片也能产出五个真实不同资产。

## 恢复的原PE限制

1. **不能重复**：统一自然组编号，逐路排除其他四路；每对目标至少列出三种原图支持的中大尺度结构差异，五图进行全部十对整图、镜像及局部包含检查。
2. **必须连续**：保留真实岩土连接段、山肩、低肩、鞍部下方岩土、共有岩基及自然山脚。雪地、共同背景及投影重叠不能证明连接，不能删低肩、挖穿背景缝或焊接邻山。
3. **必须有特征点**：每路至少三个不同的中大尺度锚点，包含具体形状和原图坐标；PE逐项保护，视觉报告逐项核验。碎石、细纹和噪点不能充数。
4. **轮廓清晰**：按从左到右的轮廓指纹保护两端、主次高点、岩肩和岩阶，不裁边、不泛化为圆包或单坡。
5. **有起伏节奏**：保留高低比例、疏密、峰间距、宽厚与转折，不生成均匀重复峰列。
6. **不能额外尖锐**：保留原图实际尖峰/钝顶和棱角，不拔尖、不拉高、不削薄、不加针柱或密集锯齿，也不统一圆丘化。

原先允许的近景岩台截断末端，只按 `close_visible_rock_edge` 自然收束可见边缘，保留 `boundary_cut=true` 来源记录；不能扩展画外台地或添加山峰。

## 完整运行流程

上传原图 → 原生识别 → 原生PE → 严格五路准入 → 五个本轮局部参考 → 五个独立原生图像生成 → 数值检查及原图/成图对照 → 原生视觉验收 → 条件重试 → 最终保存。

首轮合格时，不请求五个备用图片模型或第二轮视觉模型。首轮有失败时，合格路保留原图，只有失败路产生重试提示词并执行一次重试；最终五图重新检查十对及全部造型条件。第二轮仍失败则停止保存，不再无限重试或悄悄换目标。

所有模型节点都在画布可见，自定义节点不调用隐藏模型。工作流总计31个节点、84条边；其中10个图像模型是5个首轮与5个备用，正常首轮实际只需5个生成。原生文本模型有识别、PE及两次条件视觉验收，共4个可见节点。

每次检查生成独立 `review_id`，结合本轮 `run_id`、原图hash及五张成图hash绑定报告。旧报告、错id、缺锚点、少于十对、缺门禁或字符串冒充布尔均不能接受。最终节点只保存与已验收hash一致的实际五图。

数值检查可判断空图、尺寸、留白、透明断裂和相似证据。对于不透明白底，白雪与底色同色可能让比较掩膜分开，因此不把分量数直接当作岩体断裂；实际连接、造型锚点、轮廓节奏和尖锐程度仍依赖原生视觉模型对当前原图的核验，模型判断可能出错，重要资产应人工复核。

## 安装与使用

1. 将更新包内 `ComfyUI-MidFar-Extract-Adaptive` 替换部署到宿主的 `custom_nodes/` 同名插件目录。先保留原目录备份，避免同时加载旧副本造成同名注册冲突。
2. 在宿主Python环境安装该目录的 `requirements.txt` 并重启ComfyUI/ByteArtist插件服务。ComfyUI宿主需提供PyTorch、`ExecutionBlocker` 和 `lazy` 输入协议。
3. 确认出现 `BAMidFarFivePlan`、`BAMidFarFiveReference`、`BAMidFarFiveInspect`、`BAMidFarFiveRetry`、`BAMidFarFiveSelect`、`BAMidFarFiveFinal` 六个新节点，以及已有的 `BAMidFarActivePrompt`。
4. 导入/粘贴完整JSON，在唯一“上传一张原图”节点选图，执行最终门禁节点所连接的完整流程。
5. 在 `output/midfar-five-quality/run_<本轮编号>/` 读取三个 `midground` PNG、两个 `background` PNG以及 `五路验收记录.json`。整个已验收批次以一个目录提交，保存异常不会留下部分最终五图。

工作流内的输入文件名 `reference.png` 是上传控件的初始值，导入后需要选择自己的原图。裁框和目标点都来自本次识别，不包含026固定坐标、旧图路径或旧预览。
