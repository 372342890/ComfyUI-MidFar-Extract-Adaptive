# 三路尺寸判断与自动缩放

`BAMidFarModelSizePlan` 读取三路刚生成的真实 GLB，测量原尺寸，再按填写的最终尺寸分别计算缩放倍数。`BAMidFarModelAudit` 接收三路倍数和计划，执行整组等比缩放、底部归位，并重新测量最终文件。

模型输入支持绝对本地路径，以及生成节点返回的输出相对路径（例如 `douyin3d/model.glb`）。相对路径从宿主 `folder_paths.get_output_directory()` 解析；尺寸判断、验收和缓存内容指纹使用同一解析规则。同一文件的相对路径和绝对路径视为重复接线。

## 填写尺寸

| 控件 | 初始值 | 含义 |
| --- | --- | --- |
| `target_longest_edge` 最终最长边 | 10 | 缩放后最长边的目标 |
| `target_width` 最终宽度 | 0 | 宽度上限 |
| `target_height` 最终高度 | 0 | 高度上限 |
| `target_depth` 最终深度 | 0 | 深度上限 |
| `up_axis` 向上轴 | Y | 两个节点必须一致；Y 时高为 Y、深为 Z，Z 时高为 Z、深为 Y |

0 关闭对应尺寸，至少填一个正数。尺寸采用模型坐标单位；需要米或厘米时，先约定每个模型单位对应的长度。

**只填写一项**：这一项达到指定尺寸。比如只要求高度 5，应将最长边设为 0、高度设为 5，其余设为 0。

**同时填写多项**：这些值共同构成尺寸上限。节点选择所有有效比值中的最小值，保持比例且至少达到一项限制尺寸；不会将宽、高、深分别拉伸。

```text
缩放倍数 = min(各已启用的目标尺寸 / 对应原始尺寸)
最终宽、高、深 = 原始宽、高、深 × 同一个缩放倍数
```

原始尺寸为 8×4×2、只填最长边 10 时，倍数为 1.25，最终尺寸为 10×5×2.5。
同时填宽 12、高 2、深 1 时，倍数为 0.5，最终尺寸为 4×2×1。
不同路按各自原始尺寸计算，所以三路可使用不同倍数。只按高度判断时，原模型高度为 0 会报错，需改用有实际长度的尺寸。

## 验证与空路

两个节点都读取实际有效路报告，空路不触发模型请求、不输出占位 GLB。
计划绑定每路原文件路径、SHA-256、向上轴和尺寸。验收重新读取源模型并重算倍率，拒绝过期计划或错误接线；导出后重新测量，确认预测尺寸、目标上限、底部中心、三角面和二进制数据。全部有效路通过后才保存模型。

仅修改场景根节点的统一变换，保留原场景节点、几何、UV、法线、贴图和材质数据。沿用原 GLB 验收的静态内嵌数据支持范围，详见 `model-audit.md`。

## 安装与发布状态

独立插件 `ComfyUI-MidFar-Model-Audit/` 包含尺寸判断与验收两个节点，放到宿主 `custom_nodes/` 并重启即可；无新增 Python 包依赖。已有原插件时，使用增量更新，避免重复注册同名节点。

原插件增量更新需包含 `model_scale.py`、`model_scale_nodes.py`、`model_audit_nodes.py`、`glb_audit.py`。保持现有注册项，并加入：

```python
from .model_scale_nodes import BAMidFarModelSizePlan

# NODE_CLASS_MAPPINGS 中
"BAMidFarModelSizePlan": BAMidFarModelSizePlan,

# NODE_DISPLAY_NAME_MAPPINGS 中
"BAMidFarModelSizePlan": "三路尺寸判断 · 自动缩放倍数",
```

本次自动尺寸版本为本地增量，未提交、推送或同步云端。完整工作流的云端依赖信息沿用原导出，原插件依赖仍指向基础版本；云端使用前必须发布并安装新插件，再更新依赖与画布。
