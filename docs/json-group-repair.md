# JSON 与自然分组修复设计

目标：修复失败证据中的格式问题和自然组拆分，重新运行一张原图到三近景、两远景的完整严格 PE 链路。已有用户授权覆盖修复、必要提交推送、安装及在线验收。

## 解析边界

新增独立 `quality_json.py`，供质量链路使用。完整 JSON 可带 BOM 或完整代码围栏；重复键、非有限数、截断内容和非对象顶层明确报错。仅在目标 bbox、target_point、landmarks.point 中允许两个数值字面量的除法，按确定值转成数值并留下记录；不执行表达式，不修补缺失括号或缺失目标。数字 id 仅在已有安全且唯一的 unit_id 能确定对应关系时规范化，并同步映射 PE 与差异项。

坐标默认是完整原图归一化坐标。非归一化坐标必须明确声明整份识别的 coordinate_space 与必要尺寸，统一转换；不根据某个数值大小猜测混用坐标的单位。原始模型输出与规范化记录均保留。

## 分组边界

新增 `recognition_contract.py`。新链路要求 grouping_contract=natural-units-v1，各目标声明 component_ids，全部十对声明 group_relations，关系只能为 connected、separated、separate_depth，并提供可见证据。组成部分共享或跨路真实连接须重新识别整组，不能通过换 id 保留拆分。is_single 表示一整组自然资产，多峰仍为 true。

close_visible_rock_edge 只适用于 kind=rock 的近景可见岩台末端；山峰和山脉不能套用该策略。bbox 重叠本身不判重复，不将不同深度的投影重叠当连接。数值校验不能代替原图复核。

## 可见复核与链路

在识别与 PE 之间增加三个可见节点：BAMidFarRecognitionContext、原生 BALLMText 分组复核、BAMidFarRecognitionFinal。Context 将原始输出、可确定的规范化结果、解析/分组问题及当前原图绑定信息交给复核模型；不隐藏调用模型。Final 校验复核绑定、完整合法 JSON、点位及自然组关系后才将规范化识别送给 PE 和 FivePlan。

截断或冲突输出不能由解析器猜测补全；可见复核模型重新观察同一原图，输出完整结果。原图分组复核最多一次，失败则在图片生成前停止。五路图片及图片验收流程保持独立、仅失败路最多重试一次、十对检查、最终全部通过后保存。

通用模板不固定 026 坐标。本轮 026 验收可追加此前已经人工对照原图确认的自然组说明，明确记录该提示的来源。

## 验证与交付

用现有失败原文和针对性样本先证明测试失败，再实现最小修复。验证重复键、截断、非法算式、数字 id 映射、混合单位、共享组成部分、跨路连接、错误岩台策略、原图绑定及工作流依赖。完整回归通过后更新远端、安装重启、验证新节点，实际运行五图链路。最终交付只使用本轮实际生成且通过门禁的图片；若门禁失败，保留准确原因和进度。
