## 已验证问题

当前原图识别只有两组合格山体。`visible_pipeline.split_prompts` 强制要求三个目标，错误为 `识别节点需要三个实际完整目标，不能虚构补足。`。末端 `BAMidFarVisibleThreePNG` 和 `visible_batch.process_three` 同样强制三图。仅放宽上游数量会留下第三路空输入、额外生成和末端失败。

## 行为

1. 分路允许一至三个实际目标，仍核验唯一 id、自然组 unit_id、完整中远景身份及 PE 一一对应。零个、超过三个、重复自然组、PE 改目标或明示不连通散石均拒绝。
2. 保留八个原分路输出端口。缺失路的提示词和路径输出空字符串，记录真实数量、有效路及空缺路，不补对象、不补图。
3. 新增生成前提示词门控节点，空提示词返回 ComfyUI `ExecutionBlocker(None)`，阻断对应图像模型执行。普通非空 PE 原样传递。
4. 新末端节点按非空路径确定实际路数，图像输入为 lazy，只请求有效路。处理并保存实际一至三张图片，空输出返回执行阻断标记，记录实际 PNG 数量，不能用透明占位图冒充素材。
5. 三图旧处理 API 保留，新增一至三图 API 共用原去重逻辑。精确重复、缩放和已验证的变光变底重复仍被拒绝，并补充精确镜像重复检测。背景不限模式保持像素及 alpha 原样。
6. 新增独立节点键 `BAMidFarAdaptivePE`、`BAMidFarActivePrompt`、`BAMidFarAdaptivePNG`，自适应工作流使用新键，避免选中旧插件同名版本。保留原导出键与旧工作流构建 API。
7. 自适应工作流只包含原图、识别、独立 PE、三条可跳过提取路和统一查重。没有面数分析或 3D 生成节点。提示词保持本次已确认的独有轮廓、连续连接、主体边界与他路排除规则，明确原图实际峰形优先于错误文本。
